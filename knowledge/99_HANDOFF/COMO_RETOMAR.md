# Cómo retomar ELERRANTE en un chat nuevo

Mensaje recomendado:

> Retoma ELERRANTE desde su memoria canónica. Lee primero `knowledge/00_CANON/ESTADO_ACTUAL.md`, luego `graphify-out/GRAPH_REPORT.md` y la wiki/notas Graphify relevantes. Confirma el SHA actual de `main` en GitHub antes de modificar nada. No reconstruyas el proyecto desde conversaciones antiguas si el repositorio ya contiene información más reciente.

## Orden de diagnóstico

1. Estado canónico.
2. Grafo / wiki Graphify.
3. Archivos fuente concretos.
4. Tests y workflows relacionados.
5. Historial/PR solamente si hace falta explicar una decisión previa.

Este archivo es deliberadamente corto: la continuidad debe depender de fuentes persistentes, no de copiar conversaciones completas.
