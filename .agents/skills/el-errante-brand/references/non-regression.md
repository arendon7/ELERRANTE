# V4 non-regression guard

Reject any public-facing change that:

- restores the terracotta E as canonical logo;
- uses `EST. 2024` or another incorrect year;
- makes gold dominant;
- restores terracotta as dominant institutional UI color;
- turns the public site into a stack of repeated cards;
- expands Home copy back into an essay-first experience;
- uses one image as filler for several major narrative roles;
- breaks store, checkout or internal operational modules;
- presents generated editorial imagery as documentary evidence.
