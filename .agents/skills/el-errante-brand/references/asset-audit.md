# Asset audit reference

Read `documentacion/V4_ASSET_AUDIT_RULES.md`.

Never promote an asset because it is visually attractive alone.

Check in this order:

1. identity correctness;
2. product/packaging truth;
3. technical quality;
4. duplicate narrative role;
5. desktop crop;
6. mobile crop;
7. alt-text intent.

Statuses: PUBLICABLE, CANDIDATE, REFERENCE, REJECTED.
