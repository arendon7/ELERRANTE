# Mapa de datos y fuentes

## Fuente actual de la demo

`assets/data.js` es la única fuente de productos, variantes, precios, inventario,
cobertura, recetas, artículos y preguntas frecuentes.

## Datos demostrativos

Todo dato marcado como `demo`, `concept`, `review` o `pending` debe sustituirse antes
de producción.

## Matriz de responsables sugerida

| Área | Datos |
|---|---|
| Gastronomía | Fórmulas, métodos, ingredientes y preparación |
| Producción | Rendimientos, capacidad, lotes y vida útil operativa |
| Calidad | Alérgenos, etiquetado, liberación y trazabilidad |
| Finanzas | Costos, precios, impuestos y margen |
| Comercial | Catálogo, promociones, eventos y cobertura |
| Jurídico | Identidad del vendedor, políticas y consentimientos |
| Tecnología | Integraciones, seguridad, copias y auditoría |
