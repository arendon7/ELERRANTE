# Performance V4

Image-led does not mean image-heavy without control.

- explicit width/height;
- responsive `srcset`/`sizes` where useful;
- lazy-load below fold;
- hero image prioritized appropriately;
- WebP/AVIF derivatives from masters;
- avoid oversized media on mobile;
- motion limited to compositor-friendly properties where possible;
- avoid JS for effects achievable cleanly in CSS.
