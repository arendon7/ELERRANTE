# Project design skills

This directory contains project-scoped Agent Skills used to design and review El Errante.

## Canonical project skill

- `el-errante-brand` — binding V4 brand, art-direction, UX and copy rules for this repository.

## External design skills

The project intentionally uses a small, relevant set of external skills rather than installing broad framework bundles that do not match the current vanilla HTML/CSS/JS stack.

Target set:

- Impeccable — design quality, typography, color, spatial design, interaction, responsive behavior and UX writing.
- Emil Kowalski `emil-design-eng` — UI craft and restrained motion.
- Emil Kowalski `find-animation-opportunities` — identify only motion that genuinely improves the interface.
- Taste Skill `design-taste-frontend` — anti-template visual design and redesign protocol.
- Taste Skill `redesign-existing-projects` — audit-first improvements for existing interfaces.
- Vercel `web-design-guidelines` — accessibility, performance and UX review gate.

External skill source and version metadata is recorded in `SKILLS_LOCK.md`.

## Precedence

When external guidance conflicts with El Errante identity or product truth, use this order:

1. `el-errante-brand` and approved master assets.
2. Current culinary/editorial canon and operational truth.
3. Accessibility and functional correctness.
4. External design skills.

External design skills are craft lenses, not authority to overwrite the brand.
