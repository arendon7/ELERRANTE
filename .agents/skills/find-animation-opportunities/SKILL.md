# Find Animation Opportunities · El Errante project install

Do not implement during this pass. Produce a restrained motion plan.

## Search for

- state changes that currently feel abrupt;
- spatial transitions where source/destination relationship is unclear;
- editorial reveals where sequence improves reading;
- image/product exploration that needs orientation;
- menu/header transitions;
- purchase feedback;
- selected section transitions that can reinforce forward movement.

## Reject motion for

- ordinary paragraphs;
- every card/item on scroll;
- decorative gold lines that repeatedly shimmer;
- permanent logo movement;
- hero backgrounds that distract from pizza/product;
- forms where motion delays completion;
- anything essential to comprehension when motion is disabled.

## Proposal format

For every accepted opportunity state:

- element/moment;
- user benefit;
- property;
- distance/scale if applicable;
- duration range;
- easing intent;
- reduced-motion behavior.

Also list rejected opportunities so over-animation does not return later.
