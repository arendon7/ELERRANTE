# AEO reference

Adapted from `sanity-io/agent-toolkit` (reviewed 2026-09-02).

AEO improves machine-readable clarity and trust; it does not guarantee citation by an AI system.

## Useful patterns

- Lead explanatory pages with a direct, accurate answer before deeper detail.
- Use descriptive headings that match real user questions.
- Prefer clear lists/tables where they genuinely improve comprehension.
- Maintain canonical URLs and avoid duplicate authority pages.
- Preserve meaningful publication/update dates.
- Expose truthful authorship and sources for technical/editorial content.
- Use structured data where it accurately models the page.
- Keep crawler policy explicit and periodically reviewed.

For El Errante, optimize deep pages (Método, Ayuda, Bitácora, Recetas, Producto) for extractability without flattening the cinematic/editorial Home experience.
