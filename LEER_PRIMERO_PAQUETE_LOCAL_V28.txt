EL ERRANTE LOCAL V2.8 — CANON DE MARCA Y CONTENIDO

Esta edición conserva como referencia aprobada la segunda versión local V2.7 y consolida:
- fotografías WebP de alta calidad;
- logo E terracota y lockup horizontal;
- fichas y textos ampliados del catálogo;
- Abastecimiento V2.5;
- Finanzas Operativas V2.7;
- una única fuente V2.8 para identidad, imágenes, galerías, versión y caché;
- fuentes JavaScript legibles materializadas desde los fragmentos históricos.

ANTES DE ABRIR
1. Descomprime el ZIP completo.
2. Ejecuta VERIFICAR_PAQUETE_LOCAL_V28.command.
3. El comando generará assets/generated/data-v28.js, app-v28.js y preprod-v28.js.
4. Continúa únicamente si termina en RESULTADO FINAL: OK.

ACCESOS
- ABRIR_EL_ERRANTE_LOCAL_V28.command: web pública.
- ABRIR_ADMIN_LOCAL_V28.command: administración y finanzas.
- ABRIR_CONTROL.command: centro de control.
- ABRIR_PRESENTACION.command: presentación navegable.
- DETENER_EL_ERRANTE_LOCAL_V28.command: cerrar el servidor.

FUNCIONAMIENTO
El servidor abre solo en 127.0.0.1 y usa el primer puerto disponible entre 8787 y 8800. Mantén Terminal abierta mientras utilizas la webapp.

DATOS
Pedidos, inventarios, mediciones, compras y movimientos financieros se guardan en localStorage del navegador. Supabase permanece inactivo porque la URL y la clave pública están vacías.

FUENTES
La aplicación ejecuta primero las fuentes legibles de assets/generated. Los archivos Base64 de assets/source se conservan como origen reproducible y fallback, no como fuente visual ni editorial.

RETORNO A GITHUB
PREPARAR_RETORNO_GITHUB_V28.command vuelve a materializar, verifica la aplicación y crea en el Escritorio un ZIP para revisión y migración posterior.
