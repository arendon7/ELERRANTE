# Design Taste Frontend · El Errante project install

Project-scoped adaptation of Taste Skill v2 principles.

## Read the brief before styling

For El Errante the brief is already explicit:

- existing site, approved visual overhaul;
- editorial gastronomic brand;
- dark / elegant / cinematic / tactile;
- black + ivory + restrained aged gold;
- moving pizzaiolo emblem;
- product and photography first;
- less surface copy;
- no generic luxury or rustic trattoria styling.

## V4 dials

Working defaults for public marketing/editorial pages:

- **layout variance:** high enough to break repeated grids, but not experimental at the cost of commerce;
- **motion intensity:** low-to-medium, concentrated in a few signature moments;
- **visual density:** low-to-medium, with strong breathing space and selected information-dense product/commerce modules.

## Anti-slop rules

- Do not center every section.
- Do not use a three-card grid simply because content count is three.
- Do not use generic gradient blobs, glass cards or icon tiles.
- Do not invent decorative features unrelated to food, fire, movement or brand.
- Do not make every section visually equal.
- Do not use fake dashboards or UI motifs in a gastronomic brand page.

## Design-system map

Before implementation identify:

- brand colors;
- display/body type roles;
- section spacing scale;
- media ratios;
- line/divider style;
- control shape;
- motion tokens;
- dark/light surface sequence.

## Pre-flight

Before declaring a page done, confirm:

- recognizable brand without reading footer;
- one strong idea per section;
- varied but coherent composition;
- mobile remains intentional;
- no unnecessary new dependency;
- no placeholder imagery/text;
- commercial actions remain obvious.
