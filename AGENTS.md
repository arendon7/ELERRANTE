# EL ERRANTE · Agent Instructions

For any public-facing design, UX, copy, motion, visual-asset or frontend work:

1. Read `.agents/skills/el-errante-brand/SKILL.md`.
2. Read `documentacion/V4_BRAND_DIRECTION.md`.
3. Preserve culinary/editorial truth from `documentacion/CANON_EDITORIAL_V30.md`.
4. Treat `documentacion/CANON_VISUAL_PRODUCTO_V305.md` as the authenticity guard for product imagery.
5. Apply the external craft skills documented in `.agents/skills/SKILLS_LOCK.md` as supporting lenses, never as authority over brand truth.

## V4 identity guard

Do not reintroduce the legacy terracotta E mark as the canonical logo. The V4 identity is the approved walking pizzaiolo tossing dough, black-dominant illustration, restrained gold, ivory ground, serif EL ERRANTE wordmark, `PIZZA CONTEMPORÁNEA`, `EST. 2019`.

`Masa · Fuego · Territorio` remains an editorial idea, not the logo descriptor.

## Public redesign posture

- Existing project, visual overhaul: audit first, preserve working functionality and information architecture where useful.
- Prefer editorial sequences to repetitive card grids.
- Image-led hierarchy; short surface copy; deeper content on dedicated pages.
- Mobile is designed independently, not merely compressed.
- No framework migration during a visual redesign unless explicitly approved.
- Never modify internal Operación/Finanzas/Inventario modules as collateral damage from the public redesign.
- Run browser/regression checks before promotion.

## Asset posture

Generated visuals are not automatically publishable. Classify them as PUBLICABLE, CANDIDATE, REFERENCE or REJECTED. Do not publish malformed logos, labels, text, products or documentary claims.

## UX quality gates

- semantic HTML;
- visible keyboard focus;
- sufficient touch targets;
- WCAG-aware contrast;
- responsive image sizing;
- reduced-motion support;
- no layout shift caused by unbounded media;
- store and checkout clarity outrank decorative storytelling.
