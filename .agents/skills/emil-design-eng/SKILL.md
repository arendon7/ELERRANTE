# Design Engineering · El Errante project install

Project-scoped adaptation of Emil Kowalski's design-engineering principles.

## Core posture

Taste shows up in small decisions. Do not compensate for weak composition with more animation or visual effects.

## Motion

- Animate only when a state, hierarchy or spatial relationship benefits.
- Entrances should generally decelerate into place rather than accelerate at the end.
- Keep common UI transitions short.
- Prefer opacity + transform for reveal motion.
- Avoid large movement distances for ordinary content.
- Avoid simultaneous animation of many unrelated elements.
- Use stagger only when it creates readable sequence.
- Respect reduced motion.

## Interaction details

- Hover should reinforce clickability, not create a second design.
- Pressed states should feel immediate.
- Focus remains visible and deliberate.
- Pointer targets should not move away from the user.
- Do not animate layout dimensions when a simpler transform can express the same state.

## El Errante signature

The brand already contains movement. Use subtle forward progression, reveal and trajectory. Do not make the pizzaiolo emblem bounce, float or loop as a novelty.

## Quality test

Ask:

- Would this still feel excellent with animations disabled?
- Does the motion help understand what happened?
- Is the easing appropriate to entering, leaving or transforming?
- Is there less motion than the first instinct suggested?
