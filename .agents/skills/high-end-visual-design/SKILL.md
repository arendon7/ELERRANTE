# High-End Visual Design · El Errante project install

Sophistication is created by editing, not adding.

## Apply

- strong type scale with few sizes;
- generous negative space;
- precise alignment;
- high-quality imagery with intentional crop;
- subtle tonal separation rather than many borders/shadows;
- one restrained accent system;
- transitions that feel composed rather than animated for novelty.

## El Errante correction

“High-end” must never become generic black-and-gold luxury. Preserve food, fire, movement, travel, the pizzaiolo emblem and Colombian interpretation as the distinctive content of the aesthetic.

## Prefer

- editorial full-bleed media;
- asymmetrical text/media compositions;
- small gold rules/captions;
- ivory paper moments inside predominantly dark sequencing;
- serif display voice paired with clean functional sans;
- tactile food/process detail.

## Avoid

- metallic gradients;
- glassmorphism;
- glossy black UI panels everywhere;
- excessive serif italics;
- gold outlines on every component;
- boutique-hotel visual clichés unrelated to food;
- low-contrast “luxury” copy.
