# Impeccable · El Errante project install

Project-scoped adaptation of Impeccable's design-review philosophy.

Always combine with `el-errante-brand`.

## Audit lenses

### Typography

- Is there a real editorial/display voice and a functional UI voice?
- Are line lengths, line heights and tracking intentional?
- Does hierarchy rely on scale and spacing rather than excessive weights?

### Color and contrast

- Is black tonal rather than crushed?
- Is ivory warm and readable?
- Is gold restrained?
- Does every text/control pass practical contrast review?

### Spatial design

- Is the page shaped by a clear composition rather than repeated containers?
- Are sections differentiated by role and rhythm?
- Are cards only used for genuinely bounded objects?

### Interaction

- Are controls obvious without ornamental chrome?
- Are hover/focus/active states complete?
- Is keyboard behavior equivalent to pointer behavior?

### Motion

- Does movement communicate hierarchy/state/progression?
- Is anything animated merely because it can be?
- Does reduced-motion preserve a complete interface?

### Responsive

- Is mobile independently art-directed?
- Are crops, touch targets and reading order intentional?
- Is there overflow, cramped type or desktop-only interaction?

### UX writing

- Are labels concrete and action-oriented?
- Is repeated explanation removable?
- Do errors, empty states and commercial conditions state what the user needs to know?

## Anti-pattern review

Reject or justify:

- card grids used as universal layout;
- generic icon tiles;
- excessive rounded rectangles;
- gradients used to manufacture visual interest;
- weak gray text on colored surfaces;
- all-Inter/all-system-font aesthetic when character is required;
- decorative animation without purpose;
- large shadows/borders used as substitute for hierarchy;
- centered-everything landing-page composition.

## Output

For an audit, rank findings by impact:

1. brand/identity failure;
2. UX/accessibility failure;
3. hierarchy/composition failure;
4. content/copy failure;
5. polish opportunity.

Fix structure before polish.
