# Visual V4 reference

Read `documentacion/V4_BRAND_DIRECTION.md`.

Fast rule:

- carbon black dominates;
- ivory creates breathing space;
- aged gold is a precise accent;
- terracotta is material color, not institutional primary;
- one hero image = one narrative job;
- serif editorial voice + clean functional sans;
- avoid generic luxury, rustic trattoria and SaaS-card aesthetics.
