ABRIR EN MAC
1. Descomprime.
2. Clic derecho en ABRIR_EL_ERRANTE.command.
3. Abrir.
4. Mantén Terminal abierta.

CAMBIAR MODO
Abre control.html:
- Vista pública: oculta señales internas.
- Validación interna: muestra estados y advertencias.
