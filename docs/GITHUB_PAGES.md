# Publicación con GitHub Pages

## Configuración inicial

La cuenta administradora del repositorio debe ingresar a:

1. `Settings`
2. `Pages`
3. `Build and deployment`
4. Seleccionar `GitHub Actions` como fuente

Después, cada `push` o merge a `main` ejecutará el workflow.

## URL esperada

Para el repositorio `arendon7/ELERRANTE`, la URL habitual del proyecto será:

```text
https://arendon7.github.io/ELERRANTE/
```

La URL exacta aparecerá en el job de despliegue y en `Settings → Pages`.

## Contenido publicado

Se publica la web pública y sus recursos.

No se publican:

- panel administrativo;
- Centro de Control;
- simulador operativo;
- Studio;
- presentación interna;
- documentación;
- scripts locales;
- ZIP;
- archivos temporales.
